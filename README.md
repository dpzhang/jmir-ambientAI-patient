# Supplemental Material for "Ambient AI Scribe Implementation and Patient Experience Across Three Health Systems: A Descriptive Multi-site Observational Study"

Authors: Dongping Zhang, Mukund Nakhate, Cheryl D. Stults, Heather L. Himelhoch, Urmila Ravichandran, Prsni Patel, Anthony Solomonides, Sien Deng, Joseph Wilcox, Naveed Rabbani, Sachin D. Shah, Veena G. Jones, Nirav S. Shah

Manuscript: [Under revision at JMIR](#)

## About this repository

This repository contains the R code, derived Bayesian model outputs, tables, and figures associated with the manuscript. The source data cannot be publicly released because of data-governance requirements at a participating health system. To support reproducibility without releasing restricted source data, the repository provides posterior draws and derived outputs from all 24 fitted Bayesian models.

The released model outputs include 18 binomial models (2 outcomes $\times$ 3 model specifications $\times$ 3 coefficient-prior settings) and 6 beta-binomial models (2 outcomes $\times$ 1 model specification $\times$ 3 precision-prior settings). These outputs are sufficient to reproduce the model diagnostics, posterior summaries, sensitivity analyses, and manuscript figures without access to the original analytic dataset or fitted `brms` model objects.

The structure and contents of the repository are detailed below.

## Contents

| Directory | Description                                                                                                                                                                                                                |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data`    | Contains the compiled `model_output.rds` object and 72 corresponding CSV files. The CSV files contain parameter and prior draws, sampler diagnostics, posterior predictive draws, and expected-probability contrast draws. |
| `scripts` | Contains the main R scripts for model specification, diagnostics, model analysis, prior sensitivity analysis, likelihood sensitivity analysis, and manuscript figures.                                                     |
| `utils`   | Contains shared settings and helper functions used by the main analysis scripts.                                                                                                                                           |
| `tables`  | Contains model diagnostic, model reporting, contextual identifiability, likelihood sensitivity, and precision-parameter learning tables generated by the scripts.                                                          |
| `figures` | Contains model diagnostic, sensitivity analysis, and manuscript figures generated by the scripts.                                                                                                                          |

## Released model outputs

The compiled R object `model_output.rds` is organized as:

```r
model_output[[likelihood]][[outcome]][[prior]][[model]][[data_type]]
```

The `likelihood` keys are `binom` and `bbinom`, and the `outcome` keys are `ltr` and `exp`. The binomial coefficient-prior keys are `weak`, `default`, and `strong`, while the beta-binomial precision-prior keys are `lower`, `moderate`, and `higher`. The `model` keys are `m0`, `m1`, and `m2`. Site labels are `Endeavor`, `UCM`, and `Sutter`; `Pooled` denotes the equally weighted estimate across the three sites.

```r
model_output = readRDS("data/model_output.rds")

model_output$binom$ltr$default$m0$draws
model_output$binom$exp$default$m1$expected_contrasts
model_output$bbinom$exp$lower$m0$posterior_predictive
```

The released data types are:

| Data type              | CSV file count | Contents                                                                                                                                       |
| ---------------------- | -------------: | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `draws`                |             24 | Parameter and prior draws, including chain and iteration identifiers.                                                                          |
| `sampler_diagnostics`  |             24 | Divergence and tree-depth records for each post-warmup iteration.                                                                              |
| `posterior_predictive` |             12 | Posterior predictive rates for the models used in the predictive-distribution figures. Observed outcome rates are not included.                |
| `expected_contrasts`   |             12 | Model-implied pre- and post-period probabilities and their differences for the models used in the primary and likelihood-sensitivity analyses. |

| Package     | Version |
| ----------- | ------: |

| `brms`      |  2.23.0 |

| `dplyr`     |   1.2.1 |

Each script can be run independently, and a suggested order is:

```sh
Rscript scripts/model_diagnostics.R
Rscript scripts/model_analysis.R
Rscript scripts/prior_sensitivity.R
Rscript scripts/likelihood_sensitivity.R
Rscript scripts/paper_figs.R
```

## Model-fitting reference

`scripts/model_fit.R` documents the original model formulas, priors, sampling settings, and fitting workflow. It is included as a reference and cannot be executed because the restricted source data are not distributed.

The public materials reproduce the downstream model-based analyses from released draws. They do not reproduce source data processing, descriptive analyses based on the restricted data, or model refitting.
