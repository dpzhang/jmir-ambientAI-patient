# Supplemental Material for "Ambient AI Scribe Implementation and Patient Experience Across Three Health Systems: A Descriptive Multi-site Observational Study"

Authors: Dongping Zhang, Mukund Nakhate, Cheryl D. Stults, Heather L. Himelhoch, Urmila Ravichandran, Prsni Patel, Anthony Solomonides, Sien Deng, Joseph Wilcox, Naveed Rabbani, Sachin D. Shah, Veena G. Jones, Nirav S. Shah

Manuscript: Under revision at JMIR

## About this repository

This repository contains the R code, derived Bayesian model outputs, tables, and figures associated with the manuscript. The source data cannot be publicly released because of participating health system's data-governance requirements. To support reproducibility without releasing the restricted source data, the repository provides posterior draws and derived outputs from all 24 fitted Bayesian models.

The released model outputs include 18 binomial models (2 outcomes, 3 model specifications, and 3 coefficient-prior settings) and 6 beta-binomial models (2 outcomes, 1 model specification, and 3 precision-prior settings). The provided outputs can reproduce the model diagnostics, posterior summaries, sensitivity analyses, and manuscript figures without access to the original analytic dataset or fitted `brms` objects.

The structure and contents of the repository are detailed below.

## Content

| Directory | Content description                                                                                                                                                                                                                   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data`    | Contains the compiled `model_output.rds` object and 72 corresponding CSV files. The CSV files are organized into parameter and prior draws, sampler diagnostics, posterior predictive draws, and expected-probability contrast draws. |
| `scripts` | Contains the main R scripts for the model specification, diagnostics, model analysis, prior sensitivity, likelihood sensitivity, and manuscript figures.                                                                              |
| `utils`   | Contains shared settings and helper functions used by the main analysis scripts.                                                                                                                                                      |
| `tables`  | Contains the model-diagnostic, model-reporting, contextual-identification, likelihood-sensitivity, and precision-parameter learning tables generated by the scripts.                                                                  |
| `figures` | Contains the model-diagnostic, sensitivity-analysis, and manuscript figures generated by the scripts.                                                                                                                                 |

## Released model outputs

The compiled R object is organized as:

```r
model_output[[likelihood]][[outcome]][[prior]][[model]][[data_type]]
```

For example:

```r
model_output = readRDS("data/model_output.rds")

model_output$binom$ltr$default$m0$draws
model_output$binom$exp$default$m1$expected_contrasts
model_output$bbinom$exp$lower$m0$posterior_predictive
```

The released data types are:

| Data type              | Models | Contents                                                                                                                                       |
| ---------------------- | -----: | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `draws`                |     24 | Parameter and prior draws, including chain and iteration identifiers.                                                                          |
| `sampler_diagnostics`  |     24 | Divergence and tree-depth records for each post-warmup iteration.                                                                              |
| `posterior_predictive` |     12 | Posterior predictive rates for the models used in the predictive-distribution figures. Observed outcome rates are not included.                |
| `expected_contrasts`   |     12 | Model-implied pre- and post-period probabilities and their differences for the models used in the primary and likelihood-sensitivity analyses. |

The binomial prior keys are `weak`, `default`, and `strong`. The beta-binomial precision-prior keys are `lower`, `moderate`, and `higher`. Site labels use `Endeavor`, `UCM`, and `Sutter`; `Pooled` denotes the equally weighted estimate across sites.

## Reproducing the analysis

The exports were generated using R 4.6.0. The required packages are listed below and should be installed before running the scripts:

```r
install.packages(c(
  "this.path",
  "brms",
  "posterior",
  "dplyr",
  "tidyr",
  "purrr",
  "ggplot2",
  "ggdist",
  "ggthemes",
  "ggh4x",
  "patchwork",
  "tidybayes"
))
```

Each script can be run independently. A suggested order is:

```sh
Rscript scripts/model_diagnostics.R
Rscript scripts/model_analysis.R
Rscript scripts/prior_sensitivity.R
Rscript scripts/likelihood_sensitivity.R
Rscript scripts/paper_figs.R
```

The scripts use `this.path` to locate the repository, so they may also be opened and sourced in RStudio. Generated CSV files are written to `tables`, and generated PNG files are written to `figures`.

## Model-fitting reference

`scripts/model_fit.R` documents the original model formulas, priors, sampling settings, and fitting workflow. It is included as a reference and cannot be executed because the restricted source data are not distributed.

The public materials reproduce the downstream model-based analyses from released draws. They do not reproduce source data processing, descriptive analyses based on the restricted data, or model refitting.
